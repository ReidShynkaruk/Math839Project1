# Math839Project1
Math839Project1, algorithms

Project_1_Code is a Jupyter Notebook file that contains a python implementation of two algorithms for computing Van Der Waerden numbers w(k;r). Each algorithm has a helper function associated with it: isValid for Algorithm A and prog for Algorithm B. Algorithm A is a python implementation of the algorithm presented in Computer-Generated Van Der Waerden Partitions by R. S. Stevens and R. Shantaram published in 1978. Algorith B is a python implementation of Algorithm B from Some New Van Der Waerden Numbers by Michael Beeler and Patrick O'Neil published in 1979.
