# Math 839 Project 1
Math839Project1, algorithms

This repository examines algorithms to find Van Der Waerden numbers, and their relative efficiency. Project_1_Code is a Jupyter Notebook file that contains a python implementation of two algorithms for computing Van Der Waerden numbers w(k;r). Each algorithm has a helper function associated with it: isValid for Algorithm A and prog for Algorithm B. Algorithm A is a python implementation of the algorithm presented in Computer-Generated Van Der Waerden Partitions by R. S. Stevens and R. Shantaram published in 1978. Algorithm B is a python implementation of Algorithm B from Some New Van Der Waerden Numbers by Michael Beeler and Patrick O'Neil published in 1979. The file contains a simple time comparison for w(3;3) with adjustable values for k and r. The new values found the two papers took many tens of hours to calculate and even with modern computers, I did not feel that they made a feasible demonstration. Therefore the much more friendly w(3;3) was used as the default value to demonstrate the validity and difference in computation time between the algorithms. k and r were made modular should anyone wish to test the algorithms on more computationally demanding numbers. I searched google scholar to see if a more efficient algorithm has been developed in the nearly 50 years since these two were created and the search turned up cold. There have been more efficient algorithms that find variations on the Van Der Waerden numbers, such as palindromic Van Der Waerden numbers or have additional constraints such as max string length. As far as a catch-all algorithm that definitively finds a specific Van Der Waerden number without outside assistance goes, Algorithm B published by Michael Beeler and Patrick O'Neil in 1979 appears to be the best currently known algorithm.
